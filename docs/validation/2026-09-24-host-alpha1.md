## Confirmed source defect and remaining diagnosis

The source used C-string-style quoted control labels and quoted menu display
labels. This explains the literal quotes and differs from the unquoted UI macro
spelling used in primary DCTL implementations. The original CPU shim discarded
those metadata arguments; the original linter actually required quoted labels.
Both are corrected in alpha.2. Source default numbers now also use plain literals.

The quoted metadata is a plausible contributor to the missing menus/toggles, but
without a host rerun it is not proven to be the sole cause. Alpha.2 supplies a
four-control classic probe, a separate picker probe and a version-distinct full
file so the next test can discriminate syntax/instance/host issues. No unobserved
GPU backend, OS fault or successful restoration is asserted.
